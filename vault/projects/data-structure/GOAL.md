# 数据结构学习目标

## 目标

形成能够解释、推演、实现、验证并迁移常见数据结构与算法的能力，而不是只记住定义和代码模板。

## 暂定最终交付物

维护一个小型 C++ 数据结构实验库。每个主要结构至少包含：

- 清楚的接口和实现；
- 正常、边界和压力测试；
- 一篇能解释表示方式、不变量和复杂度的概念笔记；
- 一个验证关键假设的实验或真实应用；
- 一道未见过的迁移题及自己的回答。

截止时间和课程考核要求尚待补充。

## 掌握等级

| 等级 | 可验证标准 |
|---|---|
| L0 未覆盖 | 尚未系统学习 |
| L1 能解释 | 能用自己的话说明用途、表示和核心机制 |
| L2 能推演 | 能闭卷画出或手算操作过程，解释边界条件 |
| L3 能实现 | 能独立实现并通过正常、边界和异常测试 |
| L4 能迁移 | 能比较替代方案，并解决陌生问题或设计实验验证判断 |

“基本掌握”至少需要达到 L3，并通过一次迁移测试。掌握状态必须链接到代码、测试、实验或复习记录作为证据。

## 检验型学习的完成条件

以下条件用于用户要求检验或实现验收时；集中讲授时不以小测打断。

1. 保留学习前的闭卷解释。
2. 修正至少一个最关键的漏洞，或确认本轮没有明显漏洞。
3. 完成代码、手算、案例或实验中的一种。
4. 完成一道新情境迁移题。
5. 更新概念笔记、[[GAPS]] 和下一步。

## 责任边界

- 自己负责：目标选择、闭卷解释、关键判断、编码实践和最终验收。
- AI 负责：资料定位、概念解释、针对性追问、出题、批改、实验辅助和记录整理。

## 教学节奏偏好

- 默认集中讲授：直接讲清一节的知识结构、原理、算法、边界与实现要点，不拆成连续的引导式问答，也不主动插入小测。
- 用户提出不理解或不会的具体位置后，再针对该处细讲。只有用户要求检验、复习或实现验收时，才出题并按证据判断掌握程度。
- 检验时不用答案已在讲解或图中直接给出的复述题；优先用未见过的情境、操作推演、实现或方案比较。
