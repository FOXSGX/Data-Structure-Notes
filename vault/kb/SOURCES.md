# 数据结构资料索引

## 证据优先级

1. 课程指定教材、讲义和题目原文。
2. 语言标准或权威参考资料，用于确认 C++ 行为。
3. 本项目可重复运行的代码、测试和实验结果。
4. AI 的解释和推导；必须能回到以上证据，无法确认时标记为推断。
